# Buntownik Marketingu – strona internetowa

Statyczna strona (HTML + CSS + JS), gotowa do publikacji na Vercel.

## Pliki
- `index.html` – strona główna
- `oferta.html`, `o-mnie.html`, `manifest.html` – podstrony
- `style.css` – wygląd (kolory zmienisz na górze pliku, w sekcji `:root`)
- `script.js` – animacje, menu mobilne, galeria
- `img/` – zdjęcia i logotypy, `fonts/` – czcionka

## Do uzupełnienia później
- Opinie klientów: `index.html`, sekcja „SEKCJA 6” (instrukcja w komentarzu)
- Cennik: `oferta.html`, komentarze „CENNIK”
